# پلتفرم ژورنال و تحلیل پرایس اکشن

ژورنال معاملاتی فارسی (RTL) برای ثبت و تحلیل معاملات بر پایه پرایس اکشن (متد ال بروکس).

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید. نیازی به نصب چیزی نیست.
(Tailwind، Chart.js، فونت Vazirmatn و FontAwesome از CDN لود می‌شوند، پس اینترنت لازم است.)

## ساختار
- `index.html` : کل برنامه (HTML + CSS + JS در یک فایل)
- `CHANGELOG.md` : تاریخچه تغییرات
- `AI_GUIDE.md` : قوانین کار با AIهای مختلف روی این پروژه

## روند کار
هر AI روی branch مخصوص خودش کار می‌کند، بعد از بررسی به `main` merge می‌شود.
